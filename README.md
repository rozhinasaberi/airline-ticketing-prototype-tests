# AirTicketPrototypeTesting

A Java Eclipse prototype for an airline ticketing system, including domain classes and an initial unit-test scaffold.

## What This Project Is About

This project contains a prototype airline ticketing model with classes for passengers, ticketing, seats, and utilities, along with a `SeatingPlanTest` test file. It appears to be an early testing-oriented version of the airline project, focused on validating seating plan behavior and package organization.

This is a **Java OOP and testing prototype project**.

## Main Concepts

- passenger and ticket domain classes
- seating plan modeling
- utility/helper classes
- JUnit test scaffolding
- Eclipse project structure

## Project Structure

- `com/cc/airline/...` - main airline source files
- `src/rojina/saberi/airticket/tests/SeatingPlanTest.java` - test class
- `META-INF/` - manifest metadata
- Eclipse project files: `.project`, `.classpath`, `.settings/`
